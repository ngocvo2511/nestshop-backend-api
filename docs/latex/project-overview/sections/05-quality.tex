\section{Remaining Integration Obligations}
MVP product policies are approved. Detailed design and verification still cover:
\begin{itemize}
\item VNPay merchant/API configuration, signature/encoding fixtures, amount conversion, result mapping and IPN acknowledgement behavior.
\item Existing URL validity/reuse and safe attempt finality; a local deadline alone cannot establish the provider's final state.
\item Endpoint contracts, DTO limits, pagination, response/error shapes, scheduler interval and exact eligible-order query contracts for Staff.
\item Separate design when optional categories, carts or email are selected; speculative tables and dependencies must not become P0 requirements.
\end{itemize}

Sandbox integration testing remains necessary before payment acceptance. P0 tests must not use production credentials or real payment transactions.

\section{MVP Delivery Criteria}
Complete P0 traceability and acceptance first. Delivery includes source code, schema/migrations, secret-free sample configuration, Swagger, clean Docker Compose instructions, coverage reports and concurrency/transaction results. If a P0 item exceeds the estimate, document a smaller compliant implementation and its remaining risks rather than silently removing the requirement.
