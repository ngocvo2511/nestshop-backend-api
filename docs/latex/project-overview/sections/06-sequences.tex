\chapter{PlantUML Sequence Diagrams}

This appendix presents all 32 business flows. P1 diagrams describe optional extensions.

\section*{Grouped Index}

\begin{itemize}

\item Authentication and profiles: SEQ-01--07.

\item Catalog, inventory and roles: SEQ-08--14; role changes: SEQ-32.

\item Customer and Staff orders: SEQ-15--21.

\item Payments, expiration and reconciliation: SEQ-22--27.

\item Health: SEQ-28; optional P1 extensions: SEQ-29--31.

\end{itemize}
